## Web 어플을 만들어보자

실제로 Express-generator를 통해서 Web 어플을 만들어보자. 웹 어플리케이션을 보존할 디렉토리로 이동하자. 그리고 거기서 아래 커맨드를 입력:  
$ express -v ejs express-app

이를 통해, 웹어플을 설치할 장소에 "express-app"이라는 폴더를 작성하고, 그 안에 웹 어플의 파일류를 작성한다. 

"-v ejs": 템플릿 엔진의 지정:  
ejs라는 탬플릿 엔진을 지정한 것. Express에서는 화면의 표시를 작성하는 탬플릿 엔진이라는 것을 지원한다. 여기서는 가장 사용법이 간단한 ejs 엔진을 보도록 하자. 

### 필요한 소프트웨어의 설치 
작성된 웹 어플에는 아직 필요한 모듈류가 준비되어있지 않다. 따라서, 웹 어플이 이용하는 각종 소프트웨어를 설치하자. 
cd express-app을 통해서 폴더내로 이동 후,
$ npm install 

-> 이걸로 웹 어플은 완성 (아무 것도 만들지 않았으나 디폴트로 간단한 표시를 하는 정도의 기능이 포함되어 있다.)

### Web 어플의 실행 
폴더 내에서 "$ npm start"를 실행. http://localhost:3000/ 을 웹브라우저에서 접근. 제대로 표시되나 확인하기.
